01

One durable execution plane (C2)

Every run claims a lease with a monotonic fencing epoch before it executes. Duplicate submissions get RUN_LEASE_CONFLICT, and a stale worker's terminal write is refused.

02

At-most-once effects (C2)

Effectful tool calls are journaled started before dispatch and done after. On resume, started-without-done is marked unknown and reconciled — never silently re-executed.

run_effects.py
test_run_effects.py
03

Streams that resume, not replay (C2)

SSE frames carry id: <seq> and accept Last-Event-ID. A dropped connection resumes from the message cursor instead of submitting a second run.

Plan, act, verify, remember (C4)

Durable goals and an evidence ledger where every claim carries a handle — path, run id, artifact digest, record id or citation. Finance, citation, code and artifact verifiers run at the answer seam.

05

A safety envelope that can refuse (C6)

Sandbox profiles report when the host cannot enforce them. Effectful calls carry HMAC tokens bound to (runId, tool, argsDigest, tenant, expiry); the escape suite covers traversal, env exfil, fork bombs and egress.

Every run exports a run → step → tool/LLM span tree with per-step cost from one pricing registry. Five SLOs carry error budgets; npm run gate:slo fails CI on breach or committed regression.

Inside the run: where each guarantee lives.

One path from admission to terminal state. Durable state sits underneath it; resume re-enters the loop from a cursor instead of rebuilding the run.
