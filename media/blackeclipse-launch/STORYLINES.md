# STORYLINES — BlackEclipse launch

Subject: BlackEclipse, an open-source agentic investment-research terminal
(28 markets, 56,516 instruments, real JDDS data, a research agent).
Requested: a product launch film. Recommendation is built; the other two are here
so the film can be swapped.

Real material: the running app (captured at 1920×1080 from a local instance),
the brand's own wordmark and eclipse mark, and live JDDS values at capture:
AMD $556.43 +8.00% / $19.97B traded, S&P 500 7,649.38 +1.31%,
Nasdaq 25,466.19 +1.60%, 161 earnings reports on the day.

---

## A — The map (recommended)

**Device:** a move you can see, and the reason you can't. **Form:** one continuous
push through the same turnover map, out into the terminal, and back.

Opens on the real market map with AMD +8.00% already moving. The film asks the
question a trader actually asks — why? — then answers by pulling back to the
terminal (the whole market on one screen) and the agent (ask in plain English,
answers with sources). The last shot returns to the map, where the move is now
attached to a reason.

- First two seconds: bubble map alive; AMD ring draws; `AMD +8.00%` lands.
- Beats: hook → tension ("the reason isn't") → reveal → proof (Discover) →
  proof (Agent) → payoff (map returns) → end card.
- Look: the product's own black-and-glass terminal, satu­rated lime accent used
  only for live numbers and the mark; Inter + JetBrains Mono; real UI as the
  material, no invented dashboards.
- Sound: no music available (not signed in); exact transition and number hits
  only, delivered silent otherwise.

## B — 28 clocks

**Device:** the sun never sets on the book. **Form:** a flight across a world
grid of exchange clocks, each cut landing on a different open market.

Opens on a single clock ticking over Karachi, then the camera pulls back to 28
clocks: Tokyo closing, London opening, New York still moving. Each clock becomes
a real instrument card from the terminal. Ends on "one terminal".

- First two seconds: one second hand sweeps; the timezone label changes.
- Beats: hook → scale → reveal → proof → payoff → end card.
- Look: a dark world map with hairline meridians, warm exchange time plates,
  the terminal entering as real screens; no glowing orbs.
- Sound: ticking clock into a single sustained note; heavier sound design.

## C — One question

**Device:** the research desk answers a real question. **Form:** a single
conversation read at poster scale, intercut with the evidence it produced.

Opens on a real saved question in Eclipse Agent ("analyze gold and find me…"),
then the answer's citations assemble beside it, each a real source from the
research layer. Closes on the terminal behind the conversation.

- First two seconds: the question is already on screen, unreadable in the
  sidebar, then a punch-in makes it legible.
- Beats: hook → question → reveal → evidence → answer → claim → end card.
- Look: the agent screen's giant "ECLIPSE AGENT" type as a recurring wall;
  live text; real citations; lime only on the verified line.
- Sound: keyboard texture under a quiet pulse; verified stamp lands hard.

**Recommendation: A** — a stranger follows it without knowing the product, and
it is carried by the one visual only this product has: the live turnover map.
