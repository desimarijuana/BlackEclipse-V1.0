# Google Forms

## Purpose

Read or update a Google Form and summarise responses honestly.

## When to use

- The user asks for form content or responses.
- A form needs a question update.

## When not to use

- A different survey tool.
- Google Workspace is not connected.

## Procedure

1. Confirm the form and the requested view.
2. Read questions before changing anything.
3. Summarise responses with counts and missingness.
4. Return the form link.

## Guardrails

- Never fabricate data, sources, prices, or dates. Missing data is `UNAVAILABLE`.
- Record the source and retrieval time for every factual value.
- Do not execute trades, move funds, or mutate external systems from this skill.
- Never expose respondent identities without consent.
- Do not claim a response rate without the invitation count.

## Output

Return the form and responses summary.
