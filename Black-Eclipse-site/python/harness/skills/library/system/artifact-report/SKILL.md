# Business Reports

## Purpose

Turn an existing body of evidence into a tight business report with a clear recommendation.

## When to use

- A weekly update, proposal, or decision brief is requested.
- The evidence already exists and only synthesis is needed.

## When not to use

- Evidence still has to be collected; use `research.deep-research`.
- A spreadsheet or deck is the deliverable.

## Procedure

1. Clarify audience, decision, and length.
2. Outline the argument before writing.
3. Use the existing evidence and cite it; do not launch a new research pass.
4. Keep the recommendation explicit and the caveats visible.
5. Render the artifact and verify it opens.

## Guardrails

- Never fabricate data, sources, prices, or dates. Missing data is `UNAVAILABLE`.
- Record the source and retrieval time for every factual value.
- Do not execute trades, move funds, or mutate external systems from this skill.
- Never pad a report to look thorough.
- Do not invent evidence to fill a section.

## Output

Return the report reference, outline, and sources.
