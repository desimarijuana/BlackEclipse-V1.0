# A data-import job

Build a job that keeps a dataset up to date without duplicates, using the import kit.

## When to use it

Use this when the user asks for this kind of finance tool in their own words. You do not need them to name the shape.

## Procedure

1. Restate what they want in one sentence and confirm the details you need.
2. Use `scaffold_kit` with the matching shape and their answers. It writes the files into the task's own copy and checks the work.
3. If a check fails, tell them in one plain sentence and offer to fix it.
4. Report the result as a job done, with proof — never as files or machinery.

## Notes

This routine is a **draft**. It does nothing until it is reviewed and switched on.
