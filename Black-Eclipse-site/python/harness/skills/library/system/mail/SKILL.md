# Mail

## Purpose

Find and draft email while keeping sending as an explicit, approved action.

## When to use

- The user asks to find, read, or draft email.

## When not to use

- Mail is not connected.
- Bulk unsolicited outreach.

## Procedure

1. Confirm the account and the search query.
2. Read the thread before drafting a reply.
3. Draft with the user's voice and no invented facts.
4. Require explicit approval before sending.

## Guardrails

- Never fabricate data, sources, prices, or dates. Missing data is `UNAVAILABLE`.
- Record the source and retrieval time for every factual value.
- Do not execute trades, move funds, or mutate external systems from this skill.
- Never send without approval.
- Do not expose other recipients' addresses unnecessarily.

## Output

Return the messages or the draft.
