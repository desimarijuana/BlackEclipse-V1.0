# Presentations

## Purpose

Build a coherent deck with a narrative, one idea per slide, and sourced exhibits.

## When to use

- The user asks for a pitch deck, slide deck, or PowerPoint file.
- An existing deck needs summarising.

## When not to use

- Word documents or PDFs.
- Bitmap-only slides where real text is required.

## Procedure

1. Agree the audience, outcome, and slide count.
2. Write the narrative outline before generating slides.
3. Create the deck with real text and editable charts.
4. Keep one message per slide and cite every exhibit.
5. Open and verify the deck before delivery.

## Guardrails

- Never fabricate data, sources, prices, or dates. Missing data is `UNAVAILABLE`.
- Record the source and retrieval time for every factual value.
- Do not execute trades, move funds, or mutate external systems from this skill.
- Do not stuff slides with paragraphs.
- Do not present an unsourced chart.

## Output

Return the deck reference, outline, and slide count.
