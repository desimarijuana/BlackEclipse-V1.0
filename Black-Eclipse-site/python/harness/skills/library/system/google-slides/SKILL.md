# Google Slides

## Purpose

Read or build a Google Slides deck with a clear narrative and verified slides.

## When to use

- The user asks for a Google Slides deck.

## When not to use

- A PPTX file deliverable.
- Google Workspace is not connected.

## Procedure

1. Confirm the deck and audience.
2. Outline the narrative before creating slides.
3. Create or update and verify each slide.
4. Return the deck link.

## Guardrails

- Never fabricate data, sources, prices, or dates. Missing data is `UNAVAILABLE`.
- Record the source and retrieval time for every factual value.
- Do not execute trades, move funds, or mutate external systems from this skill.
- Do not overwrite an existing deck without reading it.
- Do not change sharing permissions implicitly.

## Output

Return the deck reference and outline.
