# Video Production

## Purpose

Turn a video brief into a validated project and a rendered file, with a storyboard and honest limits.

## When to use

- A short video, animation, or edited clip is requested.
- A storyboard or subtitle pass is needed.

## When not to use

- A static image or chart.
- Content that requires footage the user has not supplied.

## Procedure

1. Write the storyboard and duration budget.
2. Create the project and validate its inputs.
3. Render a draft and inspect it.
4. Fix timing, audio, and subtitle issues.
5. Render the final and verify the file plays.

## Guardrails

- Never fabricate data, sources, prices, or dates. Missing data is `UNAVAILABLE`.
- Record the source and retrieval time for every factual value.
- Do not execute trades, move funds, or mutate external systems from this skill.
- Do not claim a render succeeded without inspecting it.
- Respect third-party rights in supplied footage.

## Output

Return the project, video reference, and storyboard.
