# Canva

## Purpose

Produce or update a Canva design and return the link or export.

## When to use

- The user asks for a Canva design or template edit.

## When not to use

- A local document or chart.
- Canva is not connected.

## Procedure

1. Confirm the design, size, and brand constraints.
2. Create or update the design through the plugin.
3. Export the requested format.
4. Verify the export opens.

## Guardrails

- Never fabricate data, sources, prices, or dates. Missing data is `UNAVAILABLE`.
- Record the source and retrieval time for every factual value.
- Do not execute trades, move funds, or mutate external systems from this skill.
- Do not use unlicensed assets.
- Never claim a design was published when it is only a draft.

## Output

Return the design reference and export link.
