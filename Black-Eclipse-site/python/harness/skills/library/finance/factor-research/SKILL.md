# Factor Research

## Purpose

Turn an economic hypothesis into a testable factor, evaluate it out of sample, and report stability, redundancy, and limitations.

## When to use

- The user wants a new alpha factor tested.
- Comparing factor hypotheses or existing definitions.
- Promoting a validated factor into a strategy.

## When not to use

- Discretionary single-name analysis.
- Publishing an unvalidated factor as production-ready.

## Procedure

1. Write the economic rationale and the expected sign.
2. Define the factor and universe explicitly.
3. Evaluate on in-sample and out-of-sample windows.
4. Check stability across regimes and redundancy against existing factors.
5. Report turnover, capacity, and failure modes.
6. Submit for promotion only when the evidence supports it.

## Guardrails

- Never fabricate data, sources, prices, or dates. Missing data is `UNAVAILABLE`.
- Record the source and retrieval time for every factual value.
- Do not execute trades, move funds, or mutate external systems from this skill.
- Avoid look-ahead and survivorship bias.
- Report multiple-testing exposure honestly.
- A factor that only works in-sample is not validated.

## Output

Return the factor definition, evaluation metrics, and explicit limitations.
