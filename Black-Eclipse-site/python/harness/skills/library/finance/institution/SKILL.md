# Institution Mode

## Purpose

Separate analysis into explicit roles, force a bull and bear debate, then a risk review, before a portfolio-manager decision.

## When to use

- A high-stakes allocation or single-name decision.
- The user wants a structured investment committee.
- Conflicting evidence needs adversarial review.

## When not to use

- Routine lookups or quick comparisons.
- Executing trades.

## Procedure

1. Define the subject, question, and the roles to run.
2. Run independent analyst passes before any shared conclusion.
3. Force a bull case and a bear case with evidence.
4. Run a risk pass on sizing, correlation, and downside.
5. Synthesise as portfolio manager; keep disagreements visible.
6. State the decision, confidence, and what would change it.

## Guardrails

- Never fabricate data, sources, prices, or dates. Missing data is `UNAVAILABLE`.
- Record the source and retrieval time for every factual value.
- Do not execute trades, move funds, or mutate external systems from this skill.
- Do not let one role's conclusion anchor the others.
- Do not suppress a dissent to produce a clean answer.
- Execution remains out of scope.

## Output

Return the role-by-role record and the final committee decision.
