Agent invokes the model with tools bound. No tool calls → final answer. On the last step the agent unbinds tools and forces a final answer, so tool-looping/local models answer from gathered evidence instead of failing blank.

Precise data is never web-sourced. Historical prices, macro series and derived metrics drop WEB from the plan; with no structured source the layer returns UNAVAILABLE rather than a web guess.

Invariants

  • One data source — all market data through JDdS; the agentic layer never queries a second source.
  • Python-authoritative agents — prompts live in prompts.py; the front door sends only agentId.
  • Honest failures — missing data → UNAVAILABLE; missing token usage records 0, never an estimate.
  • Read-only tools — max steps, per-tool + run timeouts, duplicate suppression, one terminal status.
  • Separate persistence — agent-memory.db (runs/events/memory), distinct from jdds.db.
