# v0.3.1

**Status: production release for a single-operator, self-hosted instance.**
Tagged on the merged `main` tree after `npm run check:all` passed on that exact
commit. It is **not** a hosted multi-tenant release, and Docker remains
unverified by decision.

## What changed since v0.3.0

| Area | What changed |
|---|---|
| **Citations** | The release gate now **withholds** an unverified citation from the released answer (`[label] (unverified source)`) instead of appending a disclosure that still contained the fabricated URL. The URL stays only in the operator blob and the Sources panel. |
| **Live gate integrity** | A subset smoke can no longer claim the gate: `MIN_LIVE_TRIALS = 30`, and the verdict names the sample size. The underspecified adversarial hallucination fixture now names Apple and the SEC source. |
| **Deterministic finance** | New `finance_calc` computes signed percentage change/return, EPS, P/E, P/S, margins, position size (reward/risk), portfolio weight (value/total), CAGR and FCF from named inputs, with formula and inputs. Its formulas match the evaluation grader (15-case agreement test). The prompt names it with worked examples and requires the returned value verbatim, including its sign. |
| **Hygiene** | Size ratchets re-pinned deliberately for the new surface; tool registry regenerated (1,025 tools). |

## Not in this release

- **Docker/container verification** — no Docker host; the entrypoint fix from
  v0.3.0 remains documented but unexercised.
- **Hosted legal/compliance** — the register in `docs/legal/README.md` still
  lists the documents a hosted service needs.
- **Citation completeness** — the single citation task needs the agent to state
  the verified source, not merely retrieve it. Follow-up work.
- External benchmark, PyPI package, ACP interop.

## Rollback

The previous release is `v0.3.0`. Check it out, `npm ci && npm run build`,
restart. Data is additive (`prisma db push`); a rollback keeps the database.
