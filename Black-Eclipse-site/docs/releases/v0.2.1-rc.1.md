# v0.2.1-rc.1

**Status: release candidate, NOT production.** The code is landed, the offline
gates are green, and the live tier is measured honestly. It still reports a
failing score, and the external review/packaging work is not done. This tag is a
checkpoint, not a production sign-off.

**Tagged.** `v0.2.1-rc.1` is an annotated tag on the merged `main` tree after the
full offline gate, the corpus gate, and the chunked Python suite passed.

## What landed

| Area | What changed |
|---|---|
| **Release gate** | The size budget was raised deliberately for the data-integrity release (ADR-H327), then ratcheted to the measured merged tree. |
| **Live measurement** | The live lane now runs only `live_eligible` tasks, provider 429s/timeouts are `UNMEASURED` with a reason, and the published benchmark falls back to the committed pinned baseline instead of `NOT MEASURED`. |
| **Graders** | `25%` is accepted for an expected fraction `0.25` in both `exact` and `financial`; the `weight` tasks no longer fail on formatting. |
| **Terminal** | V2 terminal merge (ADR-H311): `terminal_run` and the verify hook run through the ONE `TerminalManager` in no-shell mode; `build_run_spec` is gone. |
| **Data integrity** | The D1-D12 fixes from the data-integrity branch are merged. |
