# v0.2.0

**The theme.** The harness could read, write and reason. It could not SEE the
project it was working in, could not VERIFY what it changed, could not keep a
conversation, and could not say what it was allowed to do. This release closes
those four gaps, and it says so in the record rather than in a claim.

## What landed

| Area | What changed | ADR |
|---|---|---|
| **The surface** | A chat coding turn used to REPLACE the finance agent's allowlist with the code profile, silently costing **441 tools** - the whole task/plan family, the whole web/research family, the unified search family, the truthful-capability diagnostics and the response-contract tools. The surface is now a UNION. | H280 |
| **Fresh installs** | The answer seam wrote a column that did not exist on a fresh `agent-memory.db`, so **every run on a clean clone crashed** after the model had already answered. | H280 |
| **Verification** | The repair loop existed, was correct, was budgeted - and had **zero production callers**. It now runs in the graph: a pinned check runs after a change, a failure goes back to the model, and the outcome is derived and published. | H281 |
| **Search** | Four tools for two questions, and the two the model reached for first were the slow ones. Now one content search (ripgrep-first, and it always names the engine) and one name search. | H284 |
| **Editing** | `expectedHash` was accepted everywhere and required **nowhere**: the model could overwrite a file it had never read. Now one `code_edit`, a **mandatory** read guard, a staleness guard, and path recovery. | H285 |
| **Memory** | The history was TRUNCATED - the decisions were gone. The dropped turns are now compacted into a fenced summary, with a deterministic skeleton that always runs and a model narrative that fails closed to it. | H286 |
| **Sight** | There was **no repo map at all**. A model had to guess a path to find out what existed. Now a deterministic, bounded map arrives in the first turn, with the seeded relevant slice, and the map's hash joins the prompt-cache key. | H287 |
| **The record** | Seven duplicate ADR numbers and two gaps; the series is now unambiguous, and a CI gate keeps it that way. | H288 |
| **The size** | The harness had a per-module ratchet but no **total** ceiling. It has one now, committed and enforced. | H288 |

## Also fixed

- The bundled SEC reference plugin was silently excluded from version control
  by a bare `sec/` gitignore pattern, so every clean clone shipped without it
  and the plugin marketplace gate failed on any checkout that was not the
  author's own tree.

## The numbers

- **7,865** Python tests, **3,725** TypeScript tests, **14/14** eval gates.
- The capability registry: **18 measured** classes, 4 honestly unmeasured.
- The harness: **368,218** lines, under a committed ceiling that must now be
  raised deliberately.

## Not in this release

- The 30% surface cut is a **multi-release program**, not one change. The
  enforcement is in place; the candidates are measured and named in
  `docs/harness/roadmap/round-3-parity-plan.md`.
- The live evaluation lane and the published benchmark numbers (W8).
- The container backend and the enforced network (W9).
- The package, the open tool registry and ACP (W10).

## How to read the release

The scorecard this release moves against is in
`docs/harness/roadmap/round-3-parity-plan.md`. It is an ESTIMATE until
someone outside this repository re-measures it against the same rubric - that
is the only thing that can falsify it.
