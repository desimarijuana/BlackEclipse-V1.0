## What changed

- **Citations are evidence-safe:** the release gate withholds an unretrieved URL
  from the answer instead of repeating it in a disclosure. The prompt now
  requires fetching the named source before citing it.
- **The live gate measures the agent:** the scripted `citations.present.001`
  fixture is excluded from the live lane (`live_eligible: false`); the corpus
  baseline/manifest were regenerated.
- **Finance is deterministic:** `finance_calc` covers signed percentage change,
  EPS, P/E, P/S, margins, position size, portfolio weight, CAGR and FCF; its
  formulas match the grader. The prompt requires the value verbatim including
  sign.
- **Live sample integrity:** a subset smoke cannot pass the gate (`MIN_LIVE_TRIALS
  = 30`).
- **Operations (Windows):** daily backup task (`install-backup-task.ps1`) and a
  5-minute health task (`install-health-task.ps1`), with logs; the Linux
  systemd/Prometheus path remains documented. Rollback artifact drill passed
  (`v0.3.0` built and served `/login` 200).
- **Legal:** a 14-document hosted contract pack as **Drafts** (Terms, Privacy,
  Risk, AI, Acceptable Use, Automated Trading, DPA, Subprocessors, Cookies,
  Trademark, Incident, Complaints, Records, Regulatory Status), DCO 1.1 and the
  contributor sign-off, and a security safe harbour.
