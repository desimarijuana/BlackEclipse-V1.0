# v0.3.0

**Status: production release for a single-operator, self-hosted instance.**
Tagged on the merged `main` tree after `npm run check:all` passed on that exact
commit. It is **not** a hosted multi-tenant release: the container path is
unverified and the hosted legal register is not complete.

## What landed

| Area | What changed |
|---|---|
| **Typed decisions** | `python/harness/decisions/`: closed `choice`/`score`/`noul` questions, a fail-closed `answered`/`review`/`unavailable` policy, a privacy-gated provider registry, a deterministic offline provider, read-only `decision_*` tools and an immutable audit record. ADR-070. |
| **Graph + quant packs** | The merged branch's quant nodes, market-read nodes, research/agent/team/output nodes, workflow assistant, trade-learning pack and Graph Studio editor work. Typed decisions are also exposed as `decision.ask` / `decision.demo` workflow nodes. |
| **Skills + memory** | Bulk enable/disable in the skill library, deep-linkable execution runs, onboarding, skill bundles/maintenance, and the personal-memory/evidence phases. |
| **Trading** | MetaTrader 5 is **attach-only** by default: the adapter refuses to launch a closed terminal (`TERMINAL_NOT_RUNNING`) unless `autoLaunchTerminal` is explicitly enabled; boolean broker config stays boolean. |
| **Canvas + chat** | Responses moved into Canvas, per-block editing, plan/quant/choices modes, project-bound conversations, native folder picker. |
| **Builds** | The project-bound self-build pipeline (brief → preview → land → scorecard) and the Builds surface. |
| **Search** | One content search (ripgrep-first, named engine) and one name search; switchable semantic retrieval. |
| **Legal** | The Legal, Compliance & Risk Management Blueprint and its document register. |
| **Release hygiene** | Production-readiness roadmap (`docs/PRODUCTION-READINESS.md`), preflight `HARNESS_AUTH=required` fix, container first-boot `prisma db push`, cold-start budget/progress logging, drift-fixture crash fix. |

## Deploying it (bare host, no Docker required)

1. `git checkout v0.3.0`
2. `npm ci && npm run build`
3. Set `HARNESS_AUTH_SECRET`, `CRON_SECRET`, `CONNECTOR_SECRET_KEY` and a
   provider key; set `HARNESS_AUTH=required` if the host is reachable by anyone
   else. Run `node --env-file=.env scripts/security-preflight.js`.
4. `npm start` (runs `scripts/doctor.js`, which creates/updates the schema), or
   the systemd path in `docs/DEPLOYMENT.md` (`scripts/deploy.sh`).
5. Keep the app on loopback behind a TLS reverse proxy. Back up the data
   directory; never commit `jdds.db`.

## Not in this release

- **Container verification.** No Docker host was available; the entrypoint now
  applies the Prisma schema, but the image/volume path itself is unexercised.
- **A fresh ≥0.9 live run.** No provider key was available; see ADR-071.
- **Hosted legal/compliance.** The register in `docs/legal/README.md` still lists
  the documents a hosted service needs (ToS, Privacy, Risk/AI disclosures, DPA).
- **External benchmark, PyPI package, ACP interop.**

## Rollback

The previous release candidate is `v0.2.1-rc.1`. Roll back by checking out that
tag, running `npm ci && npm run build`, and restarting the service. Data written
by v0.3.0 is additive (new tables/columns via `prisma db push`); a rollback keeps
the database and does not delete data.
