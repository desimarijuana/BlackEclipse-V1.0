# v0.3.3

**Status: desktop release.** This tag adds a native Windows application around
the existing stack and roughly halves what a user downloads and installs.

The browser front door is unchanged: `npm run dev`, `npm start`, `black eclipse`
and `start-eclipse.vbs` behave exactly as before, and the four launcher files are
untouched.

## The desktop app

Tauri 2 shell (3.4 MB) over the existing Next server; the Python harness is still
supervised by `python-runtime.ts` and was not modified.

| | |
| --- | --- |
| Install | per-user, no administrator rights, no Node.js, no Python |
| First run | no account, no sign-in, database seeded automatically |
| Origin | `127.0.0.1:3100` — loopback only, so no TLS proxy is needed |
| Notifications | WebView2 has no Notification API; an injected shim maps the standard constructor onto a native toast |
| Data | `%LOCALAPPDATA%\BlackEclipse\data`, preserved across uninstall |
| Lifecycle | one owned child process, attach-if-running, never kills a server it did not start, crash panel if it dies |

## Size

| | Before | v0.3.3 |
| --- | ---: | ---: |
| Download (slim) | 268 MB | **138 MB** |
| Installed (slim) | 1,411 MB | **839 MB** |
| Offline edition | — | 255 MB download |

Removed 114 MB of junk (harness tests, site-package tests, build-only modules).
Five optional packs — browser automation, machine learning, documents, computer
control, server-side charts — moved out of the core (414 MB), all lazily imported
so the core runs without them.

**A regression was found and fixed by testing the offline edition:** pruning
`*.dist-info` broke `plotly`, which reads its own version metadata at import.
The metadata is kept.

## Not included

- The 12 MB stub downloader and the onboarding pack chooser. They need published
  assets to download from; this release provides them.
- Silent self-update. Update *checking* works through the existing signed
  manifest; applying is `winget upgrade` or reinstall.
- Docker (C4) remains an operator step by ADR-071.

## Unsigned

The installer carries no code-signing certificate. The first run shows
"Windows protected your PC"; verify the SHA-256 in `SHA256SUMS.txt` and choose
*More info → Run anyway*. `winget install BlackEclipse.BlackEclipse` strips the
Mark-of-the-Web and normally skips that prompt.
