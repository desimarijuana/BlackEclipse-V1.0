# Navigation â€” Where Things Live

**Who this is for:** anyone asking "which file do I open to change X?"

This doc is also the **update trigger table**: when you add, move, or rename a
top-level folder or a major module, update the relevant row here in the same
change. That is the mechanism that keeps docs from drifting.

## Top-level map

```
Black-Eclipse-site/
  src/
    app/            Next.js App Router: page.tsx + api/**/route.ts
    components/     UI â€” screens, layout, chat, ui primitives, workspaces
                    (graph-studio/ = the visual workflow editor screens)
    lib/            All logic: data, scraper, agent, domains
                    (graph-studio/ = the canonical Workflow IR + node registry)
    hooks/          Shared React hooks
    types/          Shared TypeScript types
    generated/      Prisma client output (gitignored â€” do not edit)
  prisma/           schema.prisma (the JDDS schema)
  scripts/          Importers, bridge, doctor, db-guard, QA, local reverse proxy
  skills/           The engineering operating system (ARCHITECT/REMEMBER/â€¦)
  rust/             Native render worker (fframes video generation â€” Phase 1 proof)
  docs/             This folder
  jdds.db           SQLite data vault (committed as a seed snapshot)
```

At the **repository root** (one level above `Black-Eclipse-site/`), there is also
a project skill root:

```
black eclipse/
  .black-eclipse/skills/   Project-carried skills (one folder per skill:
                           skill.json + SKILL.md). Currently the twelve CFA
                           Level I skills â€” `cfa.00` index, one `cfa.01`-`cfa.10`
                           per exam topic (Equities first), and `cfa.99`
                           exam preparation.
```

A project skill root is resolved from the nearest `.git` ancestor, is **untrusted
until an operator records `trust_root`**, and each skill ships inert (`status:
disabled`) until enabled. See `python/harness/skills/project_skills.py` and
`docs/harness/memory-skills-evolution-plan.md`.
